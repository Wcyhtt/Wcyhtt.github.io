# 吴宸宇个人主页

本目录是可直接部署的静态网站，不需要安装依赖或执行构建命令。

## 发布到 GitHub Pages

1. 登录自己的 GitHub 账号，创建公开仓库，名称为“你的用户名.github.io”。如果同名仓库已存在，不要覆盖，先检查其中内容。
2. 将本压缩包解压，把 index.html、style.css、app.js、favicon.svg、project-note.txt 和 .nojekyll 放在仓库根目录。不要只上传 ZIP 文件。
3. 在仓库 Settings → Pages 中，选择 Deploy from a branch，分支选 main，目录选 / (root)，保存。
4. 部署完成后，从 Pages 设置页面获取真实网站地址。
5. 用大陆手机网络和校园网分别测试：打开首页、操作机械臂、切换实验图表、查看实验详情。验证通过后再给老师发送。

免费 Pages 使用公开仓库；上传的网站代码和内容均会公开。
GitHub Pages 是境外托管，本包不承诺任何地区网络的访问质量。
页面资源均为本地文件，不依赖 ChatGPT 登录或外部脚本、字体库；论文链接需要另外访问对应网站。
